# Release Notes / 发布说明 (v5.4.2)

## 会话清理

- 支持 Usage Monitor 1.5.5 的 SQLite 账本和 JSON 迁移备份, 清除已删会话的标题与提问, 保留用量和费用
- 勾选 **Usage Monitor 会话记录** 后点击 **刷新**, 可补扫已删会话

---

## Session cleanup

- Support Usage Monitor 1.5.5's SQLite ledger and JSON migration backup, clearing titles and prompts for deleted sessions while keeping usage and costs
- Select **Usage Monitor session history** and click **Refresh** to clean up previously deleted sessions

---

## 安装 / Installation

- **Windows**: 下载 `anti-power-windows.exe` 安装运行 / Download and run `anti-power-windows.exe`
- **macOS (Universal)**: 下载 `anti-power-macos-universal.dmg` 安装 (未签名, 首次打开若提示 "已损坏", 运行 `xattr -cr /Applications/Anti-Power.app`) / Download `anti-power-macos-universal.dmg` (unsigned; if macOS reports it is damaged, run `xattr -cr /Applications/Anti-Power.app`)
- **Linux**: 下载 `anti-power-linux.AppImage` 运行 / Download and run `anti-power-linux.AppImage`
